# v0.1.1

v0.1.1 consolidates Docker delivery, release hardening and public documentation
for the one-shot AMD64 Bourse Direct acquisition and Ghostfolio preview.

## Changes

- Start directly from the published image with the Compose and environment
  examples in the README. No clone, build or archive extraction is required.
  The browser seccomp profile is still installed on the Docker host and verified
  by checksum. The connection still uses an attached terminal.
- Review clearer setup instructions, synthetic JSON/YAML examples and safe
  support reporting. Docker log retention stays disabled; fixed terminal codes
  can be reported without publishing private account data or retrying a login.
- The final image excludes build-only curl, unzip and Python venv tooling while
  retaining system Python for the vault proxy, the application environment,
  Bitwarden CLI and the qualified browser.
- Image builds and CI are AMD64-only, matching the supported connection path.
- Optional archives pin both their Compose file and README image example to
  the pushed image digest. The release also supplies `IMAGE_DIGEST` and
  `SHA256SUMS`. The workflow binds the registry manifest to the exact image that
  passed vulnerability scanning and the offline image smoke check.
- Security/build guidance now describes the actual release paths. Broker-page
  changes have an explicit requalification procedure, preserving one-attempt
  authentication and uncertain-result fences.

## Upgrade and rollback

Keep the same Compose project name and persistent state volume. Use this
release's image reference from `IMAGE_DIGEST` as `BOURSEDIRECT_IMAGE`, then run
`docker compose pull`. Pulling an image does not connect to the broker. A later
connection is a deliberate interactive `docker compose run --rm bitwarden connect`.
Do not delete or replace retained state to bypass an unfinished attempt.

The v0.1.0 image and release assets remain available for deliberate rollback;
this release changes packaging and guidance without migrating financial state.

## Boundaries

There is no automatic scheduling, broker retry or financial write. The rolling
90-day notice window remains a preview rather than complete historical coverage.
Vault/environment delivery and the existing exact private HTTP option remain
unchanged. The importer package split is deferred to a later release.
