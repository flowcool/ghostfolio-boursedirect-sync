# v0.1.0

v0.1.0 packages a one-shot Bourse Direct acquisition and Ghostfolio preview for
Linux AMD64. It is intended for an operator who wants to review recent operation
notices and saved diagnostics before making any separate decision about their
portfolio.

## Included

- Docker Compose service `bitwarden`, using the published versioned container
  image and an isolated persistent state volume.
- Bitwarden-compatible vault credentials and TOTP-based Bourse Direct login,
  with original operation notices and private acquisition receipts retained.
- A rolling 90-day operation-notice window; no monthly statement cross-check is
  required.
- Explicit or first-run terminal selection of one PEA or PEA-PME and one existing
  Ghostfolio account. The chosen pair is retained. Configured account fields are
  respected; conflicts with retained selection stop the run.
- A Ghostfolio account and activity snapshot plus a dry-run report. Supported
  activity includes EUR buys, sells and net-received dividends dated on the
  Bourse Direct booking date.
- Diagnostics for missing security mappings, currency conflicts, unsupported
  operations and existing-record differences. Rows without an ISIN are skipped;
  unsupported rights operations are reported for review and are not converted.
  Unknown operations remain visible for review.

## Boundaries

The release never creates, updates or deletes Ghostfolio financial records and
does not schedule itself. A report is a preview; an exception-free run does not
establish complete account history. The acquisition window is limited to notices
offered within 90 days, and the connector does not cross-check monthly statements.
Mappings must be verified and supplied by the operator. The supported release
image is `linux/amd64`.

The default Ghostfolio connection uses HTTPS and a permanent Security Token.
For an existing trusted private Docker network, the optional
`compose.ghostfolio.yaml` overlay permits only `http://ghostfolio:3333` and checks
that its connected peer has an RFC1918 address. The external network must already
exist; the default Compose project does not join it.
