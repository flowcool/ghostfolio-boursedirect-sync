# Archive

This directory preserves material from earlier project stages. The archived
statement-based CLI guide and findings file are historical records; they do not
describe the v0.1.0 Compose product or authorize live financial operations.

- [Offline CLI guide](offline-cli-guide.md): prior statement import, review and
  laboratory workflow. Use a source checkout to follow it.
- [Findings](FINDINGS.md): historical project evidence and decisions.

For the supported acquisition and preview, start with the
[current README](../../README.md), [v0.1.0 release notes](../releases/v0.1.0.md),
and [current design contracts](../design/index.md).
