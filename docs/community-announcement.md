# Community announcement — unsent draft

v2.2.0 is published. Keep this draft unsent until Florent approves publication
after reviewing the installation proof.
Do not change repository topics as part of this draft.

Bourse Direct to Ghostfolio imports original EUR PEA and PEA-PME operation
notices. v2.2 adds a read-only PDF folder source. Paperless-ngx remains optional.
The Docker image supports amd64 and arm64. The first run is a simulation.

It supports BUY, SELL and validated coupon rows. It preserves duplicate checks
and stops writes on unreadable evidence. It holds corporate actions. It does
not support CTO, scanned PDFs, general currency conversion or complete fiscal
history. It has no broker login.
Foreign shares bought on European venues in EUR must map to the EUR listing;
see the [EUR listing guide](troubleshooting.md#foreign-shares-bought-in-eur).

Start with the [installation guide](getting-started.md) and the
[v2.2.0 release artifacts](https://github.com/flowcool/ghostfolio-boursedirect-sync/releases/tag/v2.2.0).
Use [GitHub Issues](https://github.com/flowcool/ghostfolio-boursedirect-sync/issues)
for questions. Keep private PDFs, credentials and financial logs out of reports.

Publication checklist: review the exact-digest lab receipt and fresh installation
result; obtain send authority. Repository topic changes need separate authority.
